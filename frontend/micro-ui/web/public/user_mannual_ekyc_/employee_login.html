DJB Employee Login & Portal Access Guide

What this page helps with: This manual guides Delhi Jal Board (DJB) internal employees step-by-step through accessing the official portal, navigating the Employee Login menu, authenticating via Keycloak SSO with 2FA Mobile OTP, and reaching the internal employee dashboard to manage vendor onboarding and eKYC operations.

Step 1: Navigating to the Delhi Jal Board Web Portal

Open your web browser and navigate to the official Delhi Jal Board ERP URL.

1Open any standard desktop or mobile web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
2In the address bar, type (or live DJB portal domain) and press Enter.
3The Delhi Jal Board Public Landing Page will load, displaying official branding, citizen quick links, and top navigation header bar.
Recommended Browser: For optimal performance and security, ensure your web browser is updated to the latest stable release.

Step 2: Accessing Employee Login Option

Locating and selecting Employee Login from the top header navigation menu.

1Look at the top-right corner of the header bar on the landing page.
2Hover over or click on the blue LOGIN button dropdown.
3Select Employee Login from the menu list (do not click Citizen Login).
4You will be redirected automatically to the secure Keycloak Single Sign-On (SSO) login portal.

Step 3: Entering Keycloak SSO Credentials

Providing your government-issued Employee ID / Username and Password.

1On the Delhi Jal Board Employee Sign In page, locate the username and password fields.
2Enter your official Username / Employee Code (e.g. EMP10245 or 9845681234).
3Enter your confidential Password. Your password is encrypted in the browser before transmission.
4Click the blue LOG IN button to submit credentials.
Single Sign-On Security: Keycloak SSO ensures your credentials are encrypted end-to-end and valid across all DJB enterprise modules.

Step 4: Mobile Authenticator / OTP Verification

Completing Two-Factor Authentication (2FA) via registered SMS or Mobile Authenticator.

1Upon credential validation, the Enter OTP verification prompt will appear.
2A 6-digit One-Time Password (OTP) will be dispatched instantly via SMS to your registered official mobile number (e.g., Sent to +91 ******4567).
3Enter the 6-digit passcode into the OTP input boxes.
4Click VERIFY & PROCEED.
Demo / Staging Mode Note: On staging/review builds, a fixed demo OTP 11111 (or 12345) is enabled and no actual SMS is sent. Live production always transmits real SMS passcodes.

Step 5: Redirection to Employee Dashboard

Accessing role-based options under the Core Services workspace.

1Once 2FA is verified, you are redirected to the Employee Home Dashboard.
2Your name, officer designation, and active zone appear in the top profile welcome bar.
3Locate the eKYC Admin card under Core Services to proceed with consumer application processing!

Common Issues & Solutions

Quick fixes for the problems people run into most.

OTP Not Received
›Wait a few seconds — it arrives by SMS on your registered mobile. Use Resend OTP if needed (up to 3 times), and check mobile network coverage.
›Not landing on the OTP screen at all? You’re probably still signed in via an existing session — log out (or use an Incognito / private window) to sign in fresh.
›Demo / review builds only: A fixed OTP 11111 is used for everyone and no SMS is sent. On the live system a real OTP is always sent to your phone.
Forgot / Reset Password
›On the login page tap Forgot password, verify with the OTP sent to your registered mobile, then set a new password.
Account Locked
›After 5 wrong password attempts the account locks for 15 minutes and unlocks automatically — or ask your system administrator to unlock it immediately.
Other Tips
›Dashboard blank? Some VPNs or restrictive network proxy configurations block embedded frames — click “Open in new tab” to view directly.
›Signed out unexpectedly? Sessions auto-expire after 1 hour of inactivity for security — simply sign in again.

Security & Your Data

›Two-factor login and role-based access control — you only see the tools and applications for your assigned role.
›Full audit log — every important administrative action is logged with user timestamp and IP for security audit.
›Independently security-audited by CERT-In empanelled security auditors.

Need more help? Contact your DJB / EKYC System Administrator.
